Questions

Frequently asked questions

Can you prove a departing employee downloaded files?

Where audit records are retained, we can show which account downloaded or synced which files, when and from which IP and device. Linking the account to the person and the files to later use usually needs device evidence or legal process as well.

Does syncing count as exfiltration?

A full sync copies a library to a device, so FileSyncDownloadedFull events matter as much as browser downloads. Whether that copy left the organisation depends on the device, which is why we match sync activity to managed or unmanaged devices.

Can you see what the attacker searched for?

Some search activity is recorded with premium audit, and file access records show what was opened even when search terms are not kept. We report which of these the tenant actually captured.

How long are SharePoint and OneDrive file records kept?

File and sharing events sit in the unified audit log, so they follow its retention: 180 days on standard audit and longer on premium audit. Sharing links and permissions that still exist can be read at any time.
