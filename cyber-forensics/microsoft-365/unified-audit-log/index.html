Microsoft 365 forensics

Unified Audit Log Investigation

The unified audit log is the main record of a Microsoft 365 incident. We preserve it and read it properly.

The Purview unified audit log records activity across Exchange, SharePoint, OneDrive, Teams and Entra ID, but searches are capped and records expire on a licence-based schedule. We export it in complete, verifiable slices and turn the AuditData fields into a timeline that a non-technical reader can follow.

Questions

Frequently asked questions

How long does Microsoft 365 keep audit log records?

Standard audit keeps most records for 180 days. Premium audit, for E5-licensed users, keeps Exchange, SharePoint, OneDrive and Entra records for a year by default, and up to 10 years with an add-on. Preserve the log as soon as an incident is suspected.

Why not just run the search ourselves?

You can, and it is worth exporting it early. Large searches are capped per query and easy to truncate without noticing, so we split exports by time and record type, check counts, and hash every file so the evidence can be relied on later.

What if auditing was turned off?

We confirm whether it was disabled, by whom and when, since that event is itself recorded. Other sources such as Entra sign-in logs, message trace and mailbox state can still answer part of the question.

Which records matter most in a mailbox compromise?

Usually MailItemsAccessed, Send, New-InboxRule, Set-InboxRule and Set-Mailbox, plus Entra events such as security info registration and consent to application. We export the full log for the period and filter afterwards, so nothing is missed by searching too narrowly.
