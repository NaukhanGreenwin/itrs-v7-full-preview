Windows Server 2016 End of Support (January 12, 2027): What Ontario Businesses Should Do Now

Windows Server 2016 gets its last security update January 12, 2027. Upgrade paths to 2019/2022/2025, Azure, Microsoft 365, ESU facts and a migration checklist.

Talk to us (289) 582-9930

Windows Server 2016 receives its final security update on January 12, 2027. After that Patch Tuesday, Microsoft stops shipping security fixes, bug fixes and technical support for it, unless the server is enrolled in the paid Extended Security Updates (ESU) program.

The Date: January 12, 2027 (and Why You Will Also See January 13)

Windows Server 2016 follows Microsoft's Fixed Lifecycle Policy. It was released on October 15, 2016 and mainstream support ended on January 12, 2022.

The dates apply to the Datacenter, Standard, Essentials and MultiPoint Premium editions alike, and containers released with Windows Server 2016 follow the same lifecycle.

What Stops on That Date, and What Does Not

Security updates stop, and that is the one that matters. Every vulnerability disclosed after January 12, 2027 gets patched on Windows Server 2019, 2022 and 2025 and stays open on an unenrolled 2016 server permanently.

The server does not switch off. On January 13 it boots, the file shares mount and users log in as normal.

Why an Unpatched Server Is a Bigger Risk Than an Unpatched PC

We covered Windows 10 end of support for GTA businesses when that deadline passed in October 2025, and the endpoint advice still holds. Servers are harder for one reason: position. A server is where the credentials, the shared files and the trust relationships live.

Insurance and compliance raise the stakes. Cyber insurance applications and renewals commonly ask whether you run unsupported operating systems, so your renewal date may be the real deadline; our cyber insurance readiness checklist covers the controls insurers usually ask about.

Your Options, With the Trade-offs Stated Plainly

  • In-place upgrade paths: 2016 to 2019, 2022 or 2025: Microsoft's upgrade path table shows Windows Server 2016 can be upgraded in place directly to Windows Server 2019…
  • Build new and migrate the workloads: The cleaner option, and usually the right one when the hardware is eight to ten years old anyway.
  • Move the workload to Microsoft 365 or Azure: For many Ontario small and mid-sized businesses the file server should not be replaced at all.
  • Extended Security Updates for Windows Server 2016: what is confirmed: Microsoft has confirmed an ESU program for Windows Server 2016.
  • Retire it, the option people forget: In almost every inventory there is a server nobody can explain: it hosts an application replaced two years ago, or a share nobody has opened since.

Windows Server 2016 Migration Checklist

Work through these in order. Each step depends on the one before it.

  • Inventory every Windows Server 2016 instance: the physical box, every virtual machine (including the test VM nobody decommissioned).
  • Record for each server what it does, who depends on it, which roles it runs (domain controller, file, print, DHCP, application) and what application sits on it.
  • Ask each application vendor, in writing, whether their current version is supported on Windows Server 2025 (or your chosen target).
  • Choose one option per server: in-place upgrade, rebuild and migrate, Microsoft 365 or Azure, ESU bridge, or retire.
  • Confirm licensing for the target version, plus any client access licences, before scheduling work.

A Realistic Plan for the Roughly 100 Days Left

Starting in early October 2026, the calendar looks like this:

  • October 2026: inventory, vendor questions and one decision per server. The vendor answers take calendar time rather than effort, so send them this week.
  • November 2026: licensing, any hardware orders and approvals, plus ESU enrolment for anything that genuinely cannot move.
  • Early to mid December 2026: migrate the remaining servers, domain controllers and application servers last.
  • Late December to January 12, 2027: buffer only.

If that schedule is already too tight for one server, that is the server ESU is for.

Questions

Frequently Asked Questions

When does Windows Server 2016 end of support happen?

Microsoft's final regular security update for Windows Server 2016 ships on January 12, 2027, which Microsoft's end-of-support page lists as the day extended support ends and Extended Security Updates start. The Microsoft Learn lifecycle table shows the extended end date as January 13, 2027 in Pacific Time.

Can I keep running Windows Server 2016 after January 12, 2027?

Technically yes. The server keeps working and nothing switches off. What you lose is security updates, so every vulnerability found after that date stays open on that machine unless it is enrolled in Extended Security Updates.

Are Extended Security Updates available for Windows Server 2016?

Yes. Microsoft offers ESUs for Windows Server 2016 for up to three years after end of support, covering critical and important security updates only. ESUs enabled by Azure Arc became generally available on August 6, 2026 with monthly pay-as-you-go billing; they support the Standard and Datacenter editions and generally require Software Assurance.

Can I upgrade Windows Server 2016 directly to Windows Server 2025?

Yes. Microsoft supports an in-place upgrade from Windows Server 2016 directly to 2019, 2022 or 2025, and recommends 2025. You need a licence for the new version, the server's roles must support in-place upgrade, and you should take a full backup and test the restore first.

Should we move to Microsoft 365 or Azure instead of buying a new server?

Often, yes, at least for part of it. File shares and user sign-in usually move well to SharePoint, OneDrive and Entra ID, which removes the need to replace the server. Applications that still need Windows Server can run as Azure virtual machines on a current version.
