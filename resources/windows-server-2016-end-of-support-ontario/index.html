The guide

Overview

Windows Server 2016 receives its final security update on January 12, 2027. After that Patch Tuesday, Microsoft stops shipping security fixes, bug fixes and technical support for it, unless the server is enrolled in the paid Extended Security Updates (ESU) program. As of early October 2026 that is about three months, roughly 100 days, away. If your business still runs a domain controller, file server, application server or virtual machine on Windows Server 2016, you have four realistic choices: upgrade it in place to Windows Server 2019, 2022 or 2025, rebuild on new hardware and migrate, move the workload to Microsoft 365 or Azure, or buy ESUs as a bridge while you do one of the first three.

This guide is written for businesses in Vaughan, Toronto, Mississauga and the rest of the GTA that need to finish this before January rather than discover it in January. It covers what Microsoft publishes about the date, what stops, each option with its trade-offs, what is actually known about ESUs for 2016, a migration checklist and a realistic plan for the time that is left.

The Date: January 12, 2027 (and Why You Will Also See January 13)

Windows Server 2016 follows Microsoft's Fixed Lifecycle Policy. It was released on October 15, 2016 and mainstream support ended on January 12, 2022. Microsoft's Windows Server end-of-support page lists January 12, 2027 as the day Windows Server 2016 extended support ends and Windows Server 2016 Extended Security Updates start, and Microsoft's Windows IT Pro blog gives the same date for the final monthly security update. The product lifecycle table on Microsoft Learn shows the extended end date as January 13, 2027, with dates given in Pacific Time. Both refer to the same cut-off: the last regular update ships on Patch Tuesday, January 12, and the product is out of support from then on.

The dates apply to the Datacenter, Standard, Essentials and MultiPoint Premium editions alike, and containers released with Windows Server 2016 follow the same lifecycle. For planning in Ontario, treat January 12, 2027 as the deadline and aim to be finished well before the holidays.

What Stops on That Date, and What Does Not

Security updates stop, and that is the one that matters. Every vulnerability disclosed after January 12, 2027 gets patched on Windows Server 2019, 2022 and 2025 and stays open on an unenrolled 2016 server permanently. Microsoft's own wording is that these devices will no longer receive Windows security updates, non-security updates, bug fixes, technical support or online technical content updates.

The server does not switch off. On January 13 it boots, the file shares mount and users log in as normal. That is exactly why this deadline gets missed: nothing visibly breaks, so nothing feels urgent, while the risk builds quietly in the background.

Third-party support moves too. Software vendors align their support matrices to the operating systems Microsoft supports, so over the following year the next version of your accounting package, ERP, backup agent or endpoint protection may not install on 2016, or may install but be formally unsupported. That is usually what forces the project, and by then it happens under pressure.

Why an Unpatched Server Is a Bigger Risk Than an Unpatched PC

We covered Windows 10 end of support for GTA businesses when that deadline passed in October 2025, and the endpoint advice still holds. Servers are harder for one reason: position. A server is where the credentials, the shared files and the trust relationships live. Active Directory authenticates everybody, the file server holds contracts, drawings and payroll exports, and the application server runs the system the business depends on. Compromise one of those and an attacker is positioned to move laterally and reach everything else, which is the pattern behind most of the incidents in our guide to ransomware protection for Ontario businesses.

Insurance and compliance raise the stakes. Cyber insurance applications and renewals commonly ask whether you run unsupported operating systems, so your renewal date may be the real deadline; our cyber insurance readiness checklist covers the controls insurers usually ask about. PIPEDA and PHIPA do not name an operating system, but they do require safeguards appropriate to the sensitivity of the information, and keeping personal or health information on a server that no longer receives patches is hard to defend as reasonable. Our PIPEDA compliance IT checklist covers the safeguards side.

In-place upgrade paths: 2016 to 2019, 2022 or 2025

Microsoft's upgrade path table shows Windows Server 2016 can be upgraded in place directly to Windows Server 2019, 2022 or 2025, so you can go straight to the current release in one hop. Microsoft recommends Windows Server 2025 as the target. An in-place upgrade keeps settings, roles and data, and it is the fastest path when the hardware is modern enough to keep.

Three conditions apply. Each Windows Server upgrade needs its own licence for the target version, unlike Windows client upgrades. Not every server role supports in-place upgrade, so check Microsoft's role and feature migration matrix for what that server actually runs. And everything comes along with the upgrade, including registry drift, half-removed software and configuration decisions nobody remembers making. Take a full backup of the operating system, applications, data and any virtual machines, test the restore, and book a maintenance window before you start.

Build new and migrate the workloads

The cleaner option, and usually the right one when the hardware is eight to ten years old anyway. Stand up a new server on Windows Server 2025, move roles and data across deliberately, test, then cut over. It costs more in planning and labour, but the old server stays available while the new one is validated, so the cutover is reversible for longer, and you finish with a documented environment instead of an inherited one. Ongoing visibility of what you run is part of our network and server management work.

Move the workload to Microsoft 365 or Azure

For many Ontario small and mid-sized businesses the file server should not be replaced at all. If it exists to hold shared files and authenticate users, that workload has a well-trodden path into SharePoint, OneDrive and Entra ID, and the hardware purchase disappears. Our Microsoft 365 migration guide explains what that involves. Where an application genuinely needs Windows Server, running it as an Azure virtual machine on a current operating system is worth pricing against a hardware refresh. IT Rapid Support does this work as Microsoft 365 and Azure migration services, including the part most plans skip: deciding what should not move at all.

Extended Security Updates for Windows Server 2016: what is confirmed

Microsoft has confirmed an ESU program for Windows Server 2016. What Microsoft has published so far:

  • Coverage runs for up to three years after end of support. Microsoft's Azure Arc team describes it as January 12, 2027 through January 2030.
  • ESUs deliver critical and important security updates only. No new features, no quality fixes, and no extension of technical support beyond activating the licences, installing the updates and fixing problems the updates cause.
  • Since August 6, 2026, ESUs enabled by Azure Arc are generally available for Windows Server 2016. You connect the on-premises server to Azure Arc and enrol it from the Azure portal, billed monthly on a pay-as-you-go basis that you can stop when the server is migrated or retired.
  • Arc-enabled ESUs support the Standard and Datacenter editions and generally require Software Assurance through a Volume Licensing program, with exceptions for machines licensed through SPLA or a Server Subscription. Check eligibility before you count on it.
  • Microsoft's end-of-support page also lists moving the workload to Azure as a way to get ESUs for three more years. For Windows Server 2012 and 2012 R2, Microsoft provided Azure ESUs at no additional charge beyond the cost of the virtual machine; confirm the 2016 terms for your licensing before assuming the same applies.

We do not quote ESU prices here because they depend on your licensing and the purchase channel; Microsoft points customers to its price list or a reseller. The practical point is that ESUs buy time for a workload that genuinely cannot move by January 12. They are not a plan on their own, and a business that buys a year of ESUs without a migration date usually ends up buying a second year.

Retire it, the option people forget

In almost every inventory there is a server nobody can explain: it hosts an application replaced two years ago, or a share nobody has opened since. Logging access for a week and then switching it off is the cheapest possible outcome.

Windows Server 2016 Migration Checklist

Work through these in order. Each step depends on the one before it.

  • Inventory every Windows Server 2016 instance: the physical box, every virtual machine (including the test VM nobody decommissioned), and vendor-managed appliances such as phone, camera, access control or lab systems that run 2016 underneath.
  • Record for each server what it does, who depends on it, which roles it runs (domain controller, file, print, DHCP, application) and what application sits on it.
  • Ask each application vendor, in writing, whether their current version is supported on Windows Server 2025 (or your chosen target), whether your current version is still supported at all, and how licence activation behaves when the machine name or hardware changes.
  • Choose one option per server: in-place upgrade, rebuild and migrate, Microsoft 365 or Azure, ESU bridge, or retire. If ESU is the answer for any server, confirm edition and Software Assurance eligibility now.
  • Confirm licensing for the target version, plus any client access licences, before scheduling work.
  • Take a full backup and prove it restores. Not the backup report, the restore. Our cloud backup and disaster recovery guide covers what a defensible backup looks like.
  • Migrate in waves, least critical server first, domain controllers and line-of-business servers last, with a tested restore before each wave.
  • After cutover, demote and decommission the old server properly, update documentation and monitoring, and check that nothing still points at it (mapped drives, scanners, DNS, scheduled tasks).

A Realistic Plan for the Roughly 100 Days Left

Starting in early October 2026, the calendar looks like this:

  • October 2026: inventory, vendor questions and one decision per server. The vendor answers take calendar time rather than effort, so send them this week.
  • November 2026: licensing, any hardware orders and approvals, plus ESU enrolment for anything that genuinely cannot move. Run the first, least critical migration to prove the process.
  • Early to mid December 2026: migrate the remaining servers, domain controllers and application servers last.
  • Late December to January 12, 2027: buffer only. Holiday coverage is thin and vendors are slow; a plan that depends on the last two weeks of December is planning to be unlucky.

If that schedule is already too tight for one server, that is the server ESU is for. Everything else should be on supported Windows Server, in Microsoft 365, in Azure, or switched off by January 12.

Questions

Frequently Asked Questions

When does Windows Server 2016 end of support happen?

Microsoft's final regular security update for Windows Server 2016 ships on January 12, 2027, which Microsoft's end-of-support page lists as the day extended support ends and Extended Security Updates start. The Microsoft Learn lifecycle table shows the extended end date as January 13, 2027 in Pacific Time. The dates apply to the Standard, Datacenter, Essentials and MultiPoint Premium editions.

Can I keep running Windows Server 2016 after January 12, 2027?

Technically yes. The server keeps working and nothing switches off. What you lose is security updates, so every vulnerability found after that date stays open on that machine unless it is enrolled in Extended Security Updates. Your cyber insurer and your PIPEDA or PHIPA obligations may have a view on that risk.

Are Extended Security Updates available for Windows Server 2016?

Yes. Microsoft offers ESUs for Windows Server 2016 for up to three years after end of support, covering critical and important security updates only. ESUs enabled by Azure Arc became generally available on August 6, 2026 with monthly pay-as-you-go billing; they support the Standard and Datacenter editions and generally require Software Assurance. Pricing depends on your licensing and channel, so get it from Microsoft's price list or your reseller.

Can I upgrade Windows Server 2016 directly to Windows Server 2025?

Yes. Microsoft supports an in-place upgrade from Windows Server 2016 directly to 2019, 2022 or 2025, and recommends 2025. You need a licence for the new version, the server's roles must support in-place upgrade, and you should take a full backup and test the restore first. If the hardware is near the end of its life, building a new server and migrating is usually the better route.

Should we move to Microsoft 365 or Azure instead of buying a new server?

Often, yes, at least for part of it. File shares and user sign-in usually move well to SharePoint, OneDrive and Entra ID, which removes the need to replace the server. Applications that still need Windows Server can run as Azure virtual machines on a current version. The right answer is per workload, which is why the inventory comes first.
