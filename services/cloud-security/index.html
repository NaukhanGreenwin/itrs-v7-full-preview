Microsoft 365 and Azure Security Baseline: Conditional Access, MFA and Admin Roles

Most cloud incidents we are called to start with an identity, not a server: a password reused from another site, a mailbox signed into from abroad, a forwarding rule nobody noticed. The baseline closes those doors first. Multi-factor authentication is enforced on every account, including executives, shared mailboxes that allow sign-in, and service accounts. Legacy authentication protocols that cannot do MFA are blocked. Conditional access policies decide what each sign-in is allowed to do based on the user, the device and the location, so an unmanaged laptop or an unexpected country is challenged or refused rather than waved through.

Administrative roles get the same discipline. Global administrator is held by as few named accounts as practical, separate from the everyday mailbox each person uses, with break-glass access documented and monitored. Day-to-day tasks use narrower roles. External sharing in SharePoint, OneDrive and Teams is set deliberately, and audit logging is confirmed on so there is evidence to read if something does go wrong. The same tenant settings are what we manage month to month in our Microsoft 365 managed services.

Cloud Backup and Data Protection

Moving to the cloud does not move the responsibility for your data. Microsoft keeps the service running and offers retention features, but deleted or encrypted content outside those windows is not something it restores for you. A separate backup of mailboxes, OneDrive, SharePoint and Teams, held outside the production tenant and checked with real test restores, is what makes recovery from ransomware, a malicious deletion or a departing employee a routine job.

Data protection also means controlling where data can go: sensitivity of shared links, which devices can download files, and how guests are reviewed and removed. Where the cloud sits alongside on-premises servers, the plan for both is covered by our backup and disaster recovery services.

Cloud security: common questions

What is cloud security?

Cloud security is the protection of data, identities, and applications that live in cloud platforms rather than on hardware in your office. For most Canadian businesses that means securing Microsoft 365 and Azure: who can sign in, what they can reach, how data is shared outside the organization, and how sign-in activity is monitored.

Is Microsoft 365 secure by default?

No. Microsoft 365 provides the security controls but does not switch all of them on for you. Default tenants commonly ship without enforced multi-factor authentication, without conditional access rules, with broad external sharing enabled, and with limited audit logging. Those settings have to be configured deliberately for the tenant to be considered secured.

Does Microsoft back up my Microsoft 365 data?

Microsoft operates the platform and protects its own infrastructure, but that is not the same as backing up your content. Retention windows for deleted mail, files, and sites are limited, and data removed outside those windows is not recoverable from Microsoft. A separate backup is what makes point-in-time recovery possible.

What cloud platforms does IT Rapid Support secure?

Work centres on Microsoft 365 and Azure, which is what most Toronto and GTA businesses run. That covers identity and access management, conditional access, email security, data protection and sharing controls, and monitoring of sign-in and administrative activity across the tenant.

How do you secure staff working from home?

Remote workers are secured at the identity and device layer rather than at the office network. That means enforced multi-factor authentication, conditional access rules that evaluate the device and location of each sign-in, endpoint protection on the machines themselves, and monitoring that flags sign-in activity that does not fit the user.

What do cloud security services include?

For a Microsoft 365 and Azure business: a security baseline (enforced multi-factor authentication, conditional access, limited and separated admin roles, external sharing rules, audit logging), email protection and authentication, device and endpoint controls for the machines that sign in, a separate backup of cloud data with tested restores, and ongoing monitoring of sign-in and administrative activity so the settings stay in place after they are applied.

Are cloud security services the same as IT security services?

Cloud security is the part of IT security that covers cloud platforms, identities and data. IT security services as a whole also cover the office network and firewall, endpoints, backups of on-premises systems, and incident response. For most Toronto and GTA businesses the two overlap heavily, because email, files and sign-ins already live in Microsoft 365. Our managed security service covers the wider picture.
